What's inside

Everything for label printing

One app to design, manage, and send — no driver installers, no SaaS account.

Label editor

Drag-and-drop canvas with text, 1D barcodes, QR codes, images, shapes, table fields, and icon elements. Full overlay inspector.

Template library

Save reusable label designs as templates. Sync across machines via Dropbox or any shared folder using atomic file writes.

Print history

Per-job audit log with one-click reprint. Every label printed is stored with its bitmap so you can reproduce it exactly later.

AWB & shipping labels

Built-in test page and sample AWB for courier workflows (Cargus, Fan Courier, and others). Renders PDF pages direct to the print head.

PDF & image import

Render any PDF page or raster image (PNG, JPEG, WebP, SVG) directly to the print head. Resize, crop, rotate, and enhance on the fly.

Multi-language UI

English and Romanian interfaces with an easily extensible i18n layer. Follows the OS locale automatically.

Transports

Six ways to reach your printer

Printer bindings persist across sessions. One label design, any configured printer, one click.

Transport Description
USB (direct) Native libUSB — bypasses the OS print queue for lowest-latency RAW jobs.
OS print queue Sends jobs through CUPS (macOS / Linux) or the Windows Spooler; works with any queue the OS already recognises.
TCP / IP Raw TCP socket to a network-connected printer or print server (configurable IP:port).
Bluetooth BLE Bluetooth Low Energy GATT — Phomemo M110 family and Marklife X4 BLE mode; no pairing required.
Bluetooth SPP Classic Bluetooth Serial Port Profile — older Marklife devices (D210, X4 fallback); requires OS pairing.
Serial port RS-232 / USB-CDC serial — for printers exposed as COM or ttyUSB devices.
